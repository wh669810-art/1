# 决策参考：商品图片整理与风险初筛

## 选择矩阵

| 证据 | 默认保留方式 |
|---|---|
| 白底完整产品图 | 产品目录外层主图 |
| 完整正面展示图 | 子目录正面图 1 |
| 不同姿势的正面图 | 子目录正面图 2 |
| 侧面、背面 | 各保留一张清晰图 |
| 尺码表 | 适用整款则放入每个适用颜色组；不适用则只保留在对应组 |
| 产品细节、面料、工艺介绍 | 有助于上架且不重复时保留 |
| 相同画面、不同文件名 | 只保留清晰度和文字可读性更好的版本 |
| 视频 | 未经明确确认不删除 |

## 颜色判断

以服装主体像素颜色为准，忽略背景、灯光和模特肤色。黑、藏青、深灰要结合面料和多个角度判断；双色同框图可作为共享展示图，但不能作为某一颜色的唯一证据。颜色不足时标记“待人工确认”，不要强行猜色。

## 风险记录字段

每个疑似款至少记录：

- 产品目录名
- 证据图片文件名
- 可读文字或图案描述
- 是否像具体品牌/角色（明确写“疑似”）
- 风险级别：高 / 中 / 低或未见明显标识
- 建议证据：商标授权、版权授权、原创源文件、委托创作合同、供应商进货凭证

## 常见误判

- 仅凭红黑、条纹、字母排版或普通几何图案就判定侵权。
- 把商品详情页里的模特照片版权问题，和衣服印花商标问题混为一谈。
- 看见 `alo`、`NASA`、`Champion`、动漫角色等清晰标识，却因为供应商说“通用款”而忽略授权核验。
- 把相似配色或版型当成品牌侵权证据；真正需要先核对的是文字、图形和整体识别效果。
